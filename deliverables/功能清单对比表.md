# 功能清单对比表

| 模块 | 升级前 | 升级后 | 兼容性结论 |
|---|---|---|---|
| 主视觉场景 | 使用程序化背景与地板图混合 | 以参考图 `d35cc568-a05a-4e53-a760-38b3c9b176e1.png` 作为主视觉底图，原有功能区继续保留 | 保留并增强 |
| 办公区功能 | 工作区、休息区、讨论区已存在 | 三个区域继续保留，位置与参考图对齐优化 | 保留并增强 |
| 角色状态切换 | AI 随机切换 + 模拟指令 | AI 切换、远程状态切换、MCP 指令切换并存 | 保留并增强 |
| 联网能力 | 仅本地 Mock WebSocket | 新增真实 WebSocket 通道，支持掉线回退 Mock | 保留并增强 |
| MCP 集成 | 无 | 新增 MCP 适配器，支持 `tools/call` 与 `mcp.tool_call` | 新增 |
| 状态面板 | 本地 HUD 统计 | HUD 增加网络状态、MCP 状态、原有统计保留 | 保留并增强 |
| 状态同步 | 仅单向本地模拟 | 支持接收远端命令并回传场景快照 | 新增 |
| 资源管线 | 手工处理 | 新增切图与多格式导出脚本 | 新增 |

## MCP 已支持的工具协议

- `tools/call` + `name: set_character_state`
- `tools/call` + `name: batch_set_character_state`
- `type: mcp.tool_call`
- `type: state_change`

## 状态映射

- `work` / `工作` / `工作中` -> `CharacterState.work`
- `rest` / `休息` / `休息中` -> `CharacterState.rest`
- `meeting` / `讨论` / `讨论中` -> `CharacterState.meeting`
