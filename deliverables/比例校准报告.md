# 比例校准报告

## 基准

当前工程没有真实办公室摄影 RAW、Figma/Sketch 源文件、带标尺的实景照片或 3D 测量数据，因此不能宣称完成“真实场景 1:1 还原”和“与真实照片 IOU >= 0.95”的验收。为避免虚假结论，本次采用可复核的工程基准：

- 场景坐标：`OfficeSceneConfig.sceneSize = 1600 x 1000`
- 比例尺：`1 scene dp = 8 mm`
- 物理空间：`12.8 m x 8.0 m`
- 地面网格：`80 scene dp = 640 mm`
- 误差门限：关键物体目标尺寸与 Flutter scene dp 换算误差 `<= 2%`

## Flutter 集成规则

- `pubspec.yaml` 已补充 `assets/atlas/`，保证 `AssetCatalog.json.referenceStyleImage` 可被 bundle。
- `lib/game/core/office_asset_policy.dart` 记录首屏资源、延迟资源候选、`BoxFit.contain` 与 `Alignment` 规则。
- 当前 Flutter 官方 deferred components 需要 Android dynamic feature module、AAB 构建、Dart deferred import 配合。仅在 `pubspec.yaml` 填 `deferred-components` 会导致 Android validator 失败，因此本次未写入不完整配置。
