## 部署方式

1. 执行 `flutter pub get`
2. 本地开发运行：

```bash
flutter run
```

3. 如需接入真实服务，可传入 WebSocket 地址：

```bash
flutter run --dart-define=OFFICE_WS_URL=wss://your-server.example/ws
```

## WebSocket / MCP 支持说明

- 若 `OFFICE_WS_URL` 未提供，系统自动回退到 Mock 联网模式
- 若提供了真实地址，则优先走 WebSocket 实时指令
- 支持的消息格式：
  - `state_change`
  - `mcp.tool_call`
  - JSON-RPC 风格 `tools/call`
